## 📱 GETTING AROUND THE APPLICATION

### Main Menu (Left Side)
The left side has all the features you need:

**Dashboard** → See overview of your school  
**Students** → Manage student information  
**Teachers** → Manage teacher information  
**Classes** → Create and manage classes  
**Attendance** → Mark daily attendance  
**Grades** → Enter and track student grades  
**Fees** → Track fee payments  
**Financial** → View financial reports  
**AI Assessments** 🧪 → Create exams with AI  
**AI Insights** 🧠 → See student performance trends  
**Settings** → Change system settings  

---

## 🎯 COMMON TASKS

### Task 1: Add a New Student

1. Click **Students** in the left menu
2. Click **Add New Student**
3. Fill in the form:
   - Name
   - Date of Birth
   - Student ID (or it auto-generates)
   - Class
   - Parent Name & Contact
4. Click **Save**

**Takes:** 2 minutes per student

---

### Task 2: Mark Daily Attendance

1. Click **Attendance** in the left menu
2. Select the **Date** and **Class**
3. List of students appears
4. Click "✓" to mark present, "✗" for absent
5. Click **Save Attendance**

**Takes:** 3-5 minutes for a class of 50 students

---

### Task 3: Enter Student Grades

1. Click **Grades** in the left menu
2. Select **Class** and **Subject**
3. Enter grades (0-100) for each student
4. Add any notes if needed
5. Click **Save Grades**

**Takes:** 5-10 minutes per subject per class

---

### Task 4: Track Fee Payments ⭐

1. Click **Fees** in the left menu
2. See list of students and payment status
3. Red = Not paid, Green = Paid, Yellow = Partial
4. Click on student to see details
5. Mark payment when received
6. System automatically sends reminder to parents

**Takes:** 2 minutes to update

---

### Task 5: Create an AI Assessment 🧪 ⭐⭐

**This is why Gaybeck is different!**

1. Click **AI Assessments** in the left menu
2. Click **Create New Assessment**
3. Fill in the form:
   - **Subject** (Math, English, Science, History, Geography)
   - **Difficulty** (Easy, Medium, Hard)
   - **Type** (Quiz, Test, Assignment, Project)
   - **Number of Questions** (1-50)
4. Click **Create**
5. **AI generates questions in seconds!**
6. Review and approve
7. Assessment ready to use

**Takes:** 5 minutes (instead of 50 hours!)

---

### Task 6: View Class Performance

1. Click **Dashboard** or **AI Insights**
2. Select your class
3. See:
   - Average performance score
   - Number of students at risk
   - Performance trends
   - Attendance overview
4. Click on any student to see details

**Takes:** 2 minutes to get insights

---

### Task 7: Generate a Report Card

1. Click **Dashboard**
2. Go to **Documents** section
3. Select **Generate Report Cards**
4. Choose class and term/period
5. Click **Generate**
6. Print or send to parents

**Takes:** 2 minutes for entire class

## ❓ FREQUENTLY ASKED QUESTIONS

### Q: How do I change my password?
**A:** Click **Settings** → **Change Password** → Enter old and new password → Click Save

### Q: How do I add a teacher to a class?
**A:** Go **Classes** → Select Class → Click **Assign Teacher** → Choose Teacher → Save

### Q: Can I see student records from previous years?
**A:** Yes! Click **Students** → Search student's name → They're stored with history

### Q: How do I see who hasn't paid their fees?
**A:** Click **Fees** → Filter by "Outstanding" → See all unpaid students → You can send reminders

### Q: Can parents see their child's grades?
**A:** Yes, if you enable Parent Portal in Settings. They see grades, attendance, and fees.

### Q: How often should I back up my data?
**A:** Minimum: Weekly. Recommended: Daily

### Q: What's the difference between a Quiz and a Test?
**A:** In Gaybeck: Both work the same way. You can use either term you prefer.

### Q: Can I create assessments offline?
**A:** Yes! Create them, then they sync when reconnected.

### Q: How many students can the system handle?
**A:** Thousands! It works the same from 50 to 5,000+ students.

### Q: Is my data secure?
**A:** Yes! Data stays on your local server. No cloud, no external access.

## 🚨 COMMON MISTAKES (And How to Avoid Them)

### ❌ Mistake 1: Not Backing Up Data
**Why:** You lose all your student records  
**How to avoid:** Back up school_management.db every week

### ❌ Mistake 2: Forgetting to Mark Attendance
**Why:** You lose attendance data  
**How to avoid:** Mark attendance immediately after roll call

### ❌ Mistake 3: Not Changing Default Passwords
**Why:** Security risk - anyone can login as admin  
**How to avoid:** Change immediately after setup

### ❌ Mistake 4: Not Assigning Students to Classes
**Why:** Students don't appear in class lists  
**How to avoid:** Assign students AT THE SAME TIME you create them

### ❌ Mistake 5: Not Using AI Assessment
**Why:** Wasting time creating assessments manually  
**How to avoid:** Try the AI Assessment feature - you'll love it!
