## 🔧 Troubleshooting Guide

### Issue: Setup fails
**Solution**: See [`QUICKSTART.md`](QUICKSTART.md) Troubleshooting section

### Issue: Port already in use
**Solution**: Change port: `python manage.py runserver 8001`

### Issue: Data won't migrate
**Solution**: See [`MIGRATION_GUIDE.md`](MIGRATION_GUIDE.md) Step 5

### Issue: Pages not loading
**Solution**: See [`README.md`](README.md) Troubleshooting section

### Issue: Database errors
**Solution**: Run migrations: `python manage.py migrate --run-syncdb`

### Issue: Static files missing
**Solution**: Run: `python manage.py collectstatic --noinput`
