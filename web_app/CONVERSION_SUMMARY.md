## 🚀 Getting Started (3 Steps)

### Step 1: Navigate to Web App
```bash
cd "web_app"
```

### Step 2: Run Setup (Choose Your OS)

**Windows:**
```bash
setup.bat
```

**Linux/Mac:**
```bash
chmod +x setup.sh
./setup.sh
```

### Step 3: Start Server
```bash
python manage.py runserver
```

Visit: `http://localhost:8000`

## 🔄 URL Routing Map

```
/                           → Dashboard
/accounts/login/           → Login page
/accounts/logout/          → Logout
/accounts/profile/         → User profile
/accounts/users/           → User management (Admin)
/students/                 → Student list
/students/create/          → Add student
/students/<id>/            → Student detail
/students/<id>/edit/       → Edit student
/students/<id>/delete/     → Delete student
/attendance/               → Attendance list
/attendance/date/<date>/   → Attendance by date
/attendance/class/<class>/ → Attendance by class
/fees/                     → Fee list

/fees/<id>/pay/           → Record payment
/grading/                  → Grade list
/grading/student/<id>/    → Student grades
```
