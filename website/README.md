# Gaybeck Starkids SMS - Marketing Website

Professional landing page for Gaybeck Starkids School Management System.

## Features

- **Responsive Design** - Works on all devices
- **Fast Loading** - Optimized for performance
- **Modern UI** - Clean and professional design
- **SEO Friendly** - Optimized for search engines
- **Contact Form** - Easy customer inquiries

## File Structure

```
website/
├── index.html          # Main landing page
├── css/
│   └── style.css       # All styling
└── js/
    └── main.js         # Interactive features
```

## Quick Start

Simply open `index.html` in a web browser. No server required for static hosting.

## Deployment

Deploy to any static website host:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Any web server

## Customization

Edit `index.html` to update:
- Company information
- Contact details
- Download links
- Feature descriptions
- Pricing details

Edit `css/style.css` to customize colors and styling.
