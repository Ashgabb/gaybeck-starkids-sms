## 📝 Deployment Instructions

### Quick Start (Local Testing)
```batch
cd website
python -m http.server 8000
```
Access: http://localhost:8000

### GitHub Pages (Recommended)
1. Go to GitHub repository settings
2. Navigate to Pages section
3. Set source to `main` branch, `/website` folder
4. Wait 2-3 minutes
5. Website live at: `https://ashgabb.github.io/gaybeck-starkids-sms/`

### Alternative Hosting
- Netlify: Auto-deploy from GitHub
- Vercel: Auto-deploy from GitHub
- Traditional: FTP upload to hosting provider
- AWS S3: Upload and serve from S3

See `website/DEPLOYMENT_GUIDE.md` for detailed instructions.
